# Cleo — TRIBE v2 sensory-load pipeline

Offline ML pipeline for an environment-scout app for autistic adults / SPD users.
Takes a 30-second mp4 clip of a physical space, runs Meta's
[TRIBE v2](https://github.com/facebookresearch/tribev2) multimodal brain-encoding
model on it, and emits per-region predicted cortical activation as JSON.

## What it predicts

TRIBE v2 outputs predicted fMRI activity on the **fsaverage5 cortical surface**
(~20k vertices) for an "average" subject. We aggregate those vertex predictions
into three groups:

- **Auditory** — primary auditory cortex (Heschl's) + auditory belt
- **Visual** — V1, early visual, lateral occipital, fusiform
- **Limbic-adjacent** — parahippocampal gyrus, entorhinal-adjacent, anterior
  insula, temporal pole

> ⚠️ TRIBE v2 predicts **cortical surface only**. Hippocampus and amygdala are
> subcortical and are *not* in TRIBE's output space. The "limbic-adjacent"
> group is a cortical proxy for limbic involvement, not a direct subcortical
> readout. Don't claim otherwise in user-facing copy.

## Install (on the GPU box)

Floor: ~24 GB VRAM. TRIBE bundles LLaMA-3.2-3B, V-JEPA2, and Wav2Vec-BERT —
they all load together at inference. Smaller GPUs need `device_map="auto"`
with CPU offload (slower).

```bash
# system deps
sudo apt-get install -y ffmpeg

# TRIBE v2
git clone https://github.com/facebookresearch/tribev2.git
cd tribev2
pip install -e .
cd ..

# Cleo
git clone <this repo> cleo
cd cleo
pip install -e .

# API key for the captioning step
export ANTHROPIC_API_KEY=sk-ant-...
```

First inference downloads model weights from HuggingFace — budget ~5 min on a
fast link.

## Run

```bash
python -m cleo.forecast --video data/test_clips/busy.mp4 --out out/busy.json
```

Output is a JSON document like:

```jsonc
{
  "video": "/abs/path/to/busy.mp4",
  "caption": "A room approximately 12m by 8m with...",
  "preds_shape": [21, 20484],
  "roi_stats": {
    "auditory":        {"n_vertices": 412, "peak": 0.83, "sustained": 0.61, "z_sustained":  1.74, "z_peak": 2.12},
    "visual":          {"n_vertices": 638, "peak": 0.55, "sustained": 0.38, "z_sustained":  0.41, "z_peak": 0.92},
    "limbic_adjacent": {"n_vertices": 511, "peak": 0.49, "sustained": 0.34, "z_sustained":  0.18, "z_peak": 0.61}
  },
  "ranking_by_sustained_z": ["auditory", "visual", "limbic_adjacent"],
  "notes": "..."
}
```

The `caption` field is what got fed to TRIBE as the text-modality input — it's
generated by Claude (vision) from 5 evenly spaced frames with a strict
objectivity system prompt (no emotional/judgmental language).

## Verification

Drop two contrasting 30s clips into `data/test_clips/` (e.g. quiet library +
busy café), run both, compare. Auditory `z_sustained` should be substantially
higher in the busy clip. If it isn't, ROI vertex indices are likely wrong — check
parcel names against `np.unique(cleo.rois.load_atlas().labels)` from a Python
shell.

## What's deliberately not built (yet)

- **Reference-clip calibration.** We use within-clip z-scoring against the
  whole-cortex distribution, not anchored against a library of canonical
  spaces. To add: process e.g. `library.mp4`, `cafe.mp4`, `club.mp4` once,
  cache their `roi_stats`, and report new clips' percentile against that
  distribution. ~30–60 min of GPU.
- **HTTP API.** The CLI is the only entrypoint. Wrapping `run_forecast` in
  FastAPI is ~30 lines.
- **Subcortical model.** No hippocampus/amygdala readout. A second encoding
  model (e.g. Neuroscout-trained) would be needed; out of hackathon scope.
- **User-facing summary.** `ranking_by_sustained_z` + `caption` is the
  material to feed Claude for the one-paragraph summary in the product. Not
  generated here.

## Layout

```
src/cleo/
  rois.py        # Destrieux parcel groups + atlas loader
  captioning.py  # Anthropic vision → objective scene paragraph
  pipeline.py    # demux → caption → TRIBE → ROI aggregation
  forecast.py    # CLI entrypoint
```
